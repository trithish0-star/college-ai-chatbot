AI Pipeline Workflow

How The College Chatbot Works

A state-of-the-art Natural Language Processing engine combining TF-IDF feature extraction and Logistic Regression classification.

Standard Query Processing Flow

When a student types a query in English or Tanglish:

1
Student Query

"CSE ku fees evlo?" or "Hostel available?"

2
Preprocessing

Lowercasing, Tokenization, Tanglish normalization

3
TF-IDF Vectorizer

Extracts n-gram numerical term frequency vectors

4
Logistic Regression

Classifies user intent (e.g. cse_fees)

5
SQLite FAQ Search

Retrieves verified institutional answer

6
Instant Response

Returns verified answer to student in <1.5s

Handling Unknown Queries & Continuous Learning
1. Low Confidence
Confidence score falls below threshold or unknown topic.
2. Polite Fallback
Bot returns courteous fallback and office contact.
3. Store in SQLite
Auto-saved in unknown_queries for admin review.
4. Admin Updates FAQ
Admin adds verified answer; model retrains dynamically!

Sequence Diagram (Message Flow)
1. Student opens chatbot UI and sends "CSE ku fees evlo?"
2. Frontend JS dispatches POST /api/chat with session identifier
3. Flask Backend receives payload and forwards to NLP Engine
4. NLP Engine applies Tanglish normalization & TF-IDF vectorization
5. Logistic Regression classifies intent -> "cse_fees" (Confidence: 0.95)
6. SQLite Database queries FAQ table for intent "cse_fees"
7. Database returns verified fee details (₹75,000 / year)
8. Flask Backend streams JSON response to Frontend
9. UI displays verified answer in WhatsApp-style chat bubble in <1.5s
